# Polaris

方塊對戰的覆盤與練習工具，附一段故事模式。在你自己的電腦上執行（Windows）。

- **覆盤**：讀 TETR.IO 的對局紀錄或 Polaris 自己的對戰錄影，逐手看哪裡可以下得更好
- **練習**：單人、40 行、解題、跟電腦對戰
- **故事模式**：從『只有一面牆的世界』開始的一段故事

> 這個 repo 只放**下載**與**問題回報**；原始碼不公開。

## 下載

到 [Releases](../../releases) 下載最新版的 `Polaris-<版號>-win64.zip`，解壓縮後雙擊 `Polaris.exe`，
遊戲會在瀏覽器裡打開。詳細說明見 zip 裡的「使用說明.txt」。

## 回報問題

- **有 GitHub 帳號**：到 [Issues](../../issues/new/choose) 選「回報問題」，照表單填。
- **沒有 GitHub 帳號**：到 [Discord 群組](https://discord.gg/Fg3uu7N2xY) 的回報頻道。

回報時請附上：遊戲頁尾顯示的**版號**、發生在哪個畫面、怎麼重現。有截圖更好。
